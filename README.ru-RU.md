# Visual-PS5 — PS5 Homebrew Studio 1.1.0

Локальная визуальная IDE для Windows: проектирование интерфейсов, управление проектами, проверка кода, генерация C++20 UI и запуск сборок через community toolchain для PS5.

**Языковой статус:** интерфейс пока на испанском. Русское руководство готово; локализация UI будет выполнена отдельно.

## Быстрый старт

1. Скачайте или соберите пакет нужной ветки разработки.
2. Распакуйте в доступный для записи каталог на Windows 10/11.
3. Запустите start.bat; если браузер не открылся, перейдите на http://127.0.0.1:47813/.

Рекомендуется PowerShell 7; Windows PowerShell 5.1 также поддерживается. Для нативной сборки нужны Git, WSL/Linux и зависимости выбранного шаблона. Сервис слушает только 127.0.0.1.

Сопровождающий сообщил об успешном тесте образа .ffpfsc на реальном оборудовании; это не гарантирует работу всех титулов и прошивок. Visual-PS5 не является официальным SDK Sony и не содержит прошивки, ключей, игр, BIOS или проприетарных файлов.
