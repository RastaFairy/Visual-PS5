# Visual-PS5 — PS5 Homebrew Studio 1.1.7

Локальная визуальная IDE для Windows: проектирование интерфейсов, управление проектами, проверка кода, генерация C++20 UI и запуск сборок через community toolchain для PS5.

**Языковой статус:** интерфейс пока на испанском. Русское руководство готово; локализация UI будет выполнена отдельно.

## Что нового в 1.1.7

- Можно импортировать шрифт TrueType (`.ttf`) и выбрать его для нативного проекта. Для OpenGL и Vulkan создаются SDF-атласы с Unicode-глифами, используемыми в проекте; если нужного глифа нет, сборка останавливается с указанием codepoint.
- Регрессионные тесты охватывают кириллицу, греческий, японский, упрощённый/традиционный китайский и корейский. Это поддержка текста в игре, а не перевод испанского интерфейса IDE; ввод через CJK IME и полная обработка RTL пока не реализованы.
- [Руководство по Unicode-шрифтам](docs/UNICODE-FONTS.en-GB.md)

- Добавлена вкладка **«Структура»**, которая отдельно показывает редактируемые визуальные экраны и состояния меню, найденные в нативном C++. Есть поиск, карта переходов, обнаруженные подписи меню и переход к строкам исходного кода. Переходы C++ выводятся статически и требуют ручной проверки.
- Исправлены кнопки действий в диалогах UltraPack и «Презентация».
- Для нативной OpenGL-сборки визуальных проектов IDE использует локальный `build.ps1` проекта и его зависимости. Это позволяет не выполнять избыточную подготовку общего SDK, которая может завершиться ошибкой на WSL/DrvFS без `metadata`.
- До сборки можно выбрать значок приложения, фон выбора, фон запуска и музыку; добавлены управление экранами и порядок слоёв отдельно для каждого экрана.
- Сопровождающий подтвердил успешную компиляцию OpenGL и упаковку UltraPack в своей среде Windows/WSL. Полная Vulkan-сборка, преобразование ATRAC9 и запуск на физической PS5 пока не проверены. См. [известные проблемы и статус проверки](PS5-Homebrew-Studio/docs/KNOWN-ISSUES.es-ES.md).

## Быстрый старт

1. Скачайте или соберите пакет нужной ветки разработки.
2. Распакуйте в доступный для записи каталог на Windows 10/11.
3. Запустите `PS5-Homebrew-Studio/start.bat`; если браузер не открылся, перейдите на http://127.0.0.1:47813/.

Рекомендуется PowerShell 7; Windows PowerShell 5.1 также поддерживается. Для нативной сборки нужны Git, WSL/Linux и зависимости выбранного шаблона. Сервис слушает только 127.0.0.1.

Успешные компиляция и упаковка сами по себе не подтверждают запуск на физической PS5; текущий статус проверки указан в документе об известных проблемах. Visual-PS5 не является официальным SDK Sony и не содержит прошивки, ключей, игр, BIOS или проприетарных файлов.
