# Créditos y atribuciones

## Proyecto principal

**Visual-PS5 / PS5 Homebrew Studio** — integración, interfaz visual, orquestación de compilaciones y generación nativa mantenidas en este repositorio por **RastaFairy**: [perfil de GitHub](https://github.com/RastaFairy) · [repositorio del IDE](https://github.com/RastaFairy/Visual-PS5).

La utilidad del IDE depende de SDK, plantillas, kits gráficos, herramientas y aplicaciones de referencia de terceros. Esta lista reconoce los proyectos upstream catalogados por el IDE y la CLI de empaquetado que integra. Los enlaces identifican a los autores o cuentas mantenedoras en GitHub; no implican que todos hayan contribuido directamente al código de Visual-PS5 ni que respalden este IDE.

## Herramientas base

El desarrollo y la validación también utilizan herramientas mantenidas por sus proyectos: [Git](https://github.com/git/git), [Node.js](https://github.com/nodejs/node), [PowerShell](https://github.com/PowerShell/PowerShell), [Python](https://github.com/python/cpython), [LLVM](https://github.com/llvm/llvm-project), [Mesa](https://gitlab.freedesktop.org/mesa/mesa), [CMake](https://github.com/Kitware/CMake) y [Ninja](https://github.com/ninja-build/ninja). Comprueba las versiones y dependencias exigidas por la revisión upstream elegida.

## Licencias y alcance de la atribución

Cada proyecto conserva sus autores, avisos, licencia y obligaciones de redistribución. La licencia de Visual-PS5 no sustituye ni unifica las licencias upstream. Antes de redistribuir código o binarios, revisa LICENSE, COPYING, NOTICE y las licencias transitivas de los commits realmente utilizados.

La tabla documenta el catálogo del IDE; no significa que todos los repositorios se descarguen o se incorporen a cada build. El software de terceros se obtiene cuando el usuario decide utilizarlo. Si falta una atribución o un dato necesita corrección, abre una issue o pull request en [Visual-PS5](https://github.com/RastaFairy/Visual-PS5).
