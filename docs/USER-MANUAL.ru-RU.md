# Руководство пользователя — PS5 Homebrew Studio 1.1.0

Обновлено: 16 октября 2026 года. Интерфейс приложения пока на испанском; перевод руководства не означает, что локализация интерфейса завершена.

## 1. Требования

Для запуска нужны Windows 10/11 и права чтения/записи в папке приложения. Рекомендуется PowerShell 7; Windows PowerShell 5.1 тоже поддерживается.

Для сборки требуются Git, WSL/Linux и upstream-зависимости выбранного backend. SharpProspero/C# требует версию .NET, указанную установленной ревизией. Для нативных шаблонов C++ нужны совместимые toolchain. UltraPack требует Python 3.10+ и репозиторий [PS5 UltraPack](https://github.com/knutwurst/ps5-ultrapack).

## 2. Установка и запуск

1. Скачайте или соберите пакет нужной ветки разработки.
2. Распакуйте его в доступный для записи каталог, избегая защищённых папок Windows.
3. Запустите start.bat и оставьте окно PowerShell открытым.
4. Если браузер не запустился, откройте http://127.0.0.1:47813/.
5. Для остановки закройте окно сервера или используйте STOP.bat.

Сервис слушает только 127.0.0.1. Не открывайте его в сеть и не меняйте bind на 0.0.0.0. Проекты по умолчанию сохраняются в Documents/PS5HomebrewStudio/Projects.

## 3. Интерфейс и визуальный проект

Холст 1920×1080 — виртуальная рабочая область, а не точный скриншот системного интерфейса PS5. Добавляйте компоненты через панель, изменяйте свойства в инспекторе, упорядочивайте элементы в иерархии и создавайте экраны. Редактор потоков связывает события с действиями notify, setText, toggleVisibility, setValue, changeColor и navigate, если их поддерживают компонент и backend.

Создайте проект, выберите backend до установки зависимостей, добавьте компоненты и ресурсы, задайте уникальные ID и настройте экраны. Запустите диагностику и исправьте ссылки на отсутствующие элементы. Сохраните с Ctrl+S. Экспорт модели или ZIP не равен сборке нативного титула.

## 4. Backend и сборка

**SharpProspero / C#:** использует реальный upstream-процесс и .NET/NativeAOT. Проверьте версию .NET для установленного коммита.

**Нативный OpenGL / C++20:** генерирует экран по контракту ps5-homebrew-ui. Изображения конвертируются в RGBA8; предел — 512×512 пикселей и 16 уникальных ID текстур на экран.

**Vulkan/RADV / C++20:** создаёт титул через PS5_VulkanTemplate и интегрирует UI в совместимый Vulkan-модуль. Нужны совместимые ревизии PS5_Vulkan, PS5_Mesa/RADV, PS5_PayloadSDK и PS5_VKHomebrewUI.

IDE выполняет настоящие upstream-скрипты и сохраняет логи. Нулевой код выхода не достаточен: для упаковки требуются eboot.bin и sce_sys/param.json. IDE не распространяет проприетарные SDK Sony и не гарантирует совместимость со всеми прошивками.

## 5. Упаковка в UltraPack

1. Откройте «Инструменты», настройте Python 3.10+ и файл backend/cli.py в UltraPack.
2. Сохраните параметры; локальные пути хранятся в .runtime/integrations.json.
3. Выберите собранный нативный проект и нажмите «Упаковать».
4. Выберите .ffpfs, .ffpfsc или .pkg. В Windows для .pkg нужен нативный helper с зависимостями.
5. Оставьте включённым параметр «Проверить содержимое относительно источника», чтобы передавать --verify. Проверка может увеличить время и потребление памяти.
6. Проверьте итоговый лог, код выхода, путь результата и предупреждения. Старый артефакт не доказывает успех текущего запуска.

Результаты находятся в packages-ultrapack и разделены по формату и времени. Упаковка идёт в фоне. По сообщению сопровождающего, созданный образ .ffpfsc успешно проверен на реальном оборудовании; это не гарантирует работу любого титула, прошивки или backend.

## 6. Тесты и устранение проблем

При установленном Node.js выполните из папки приложения node --check app.js, node --check runtime/native-generator.js и node runtime/test-native-generator.js. Они проверяют синтаксис JavaScript и кейсы генератора, но не заменяют сборку полной PS5 toolchain и тест на консоли.

Если сервер не запускается, сохраните полную ошибку и проверьте PowerShell и права. При ошибках сборки запишите backend, версии и коммиты upstream, полный лог и код выхода. При сбое UltraPack проверьте Python/cli.py, eboot.bin, sce_sys/param.json и права на каталог вывода. Не публикуйте секреты.
